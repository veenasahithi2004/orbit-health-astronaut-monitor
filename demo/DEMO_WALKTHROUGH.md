# Orbit Health demo walkthrough

This script is intended for a short live demo or a recording of up to 30 seconds. Use only the bundled fictional crew data.

| Time | Show | Suggested narration |
| --- | --- | --- |
| 0–5 sec | Open dashboard and crew selector | “Orbit Health is a crew wellness check-in concept for long-duration missions.” |
| 5–12 sec | Health cards and trend chart | “Crew can review current indicators alongside recent heart-rate and sleep patterns.” |
| 12–18 sec | Mission context panel | “Mission conditions add context; an environmental radiation reading is not an individual diagnosis.” |
| 18–26 sec | Enter readings and save a check-in | “A crew member can record a check-in and see it added to local history.” |
| 26–30 sec | Updated recent activity and prototype notice | “The sample data and prompts are illustrative. Real care follows approved flight medical procedures.” |

## Before recording

1. Install Node.js 18 or newer.
2. Run `npm start` in the project folder.
3. Open <http://localhost:3000> and maximize the browser.
4. Keep the **SIMULATION DATA** label visible.
5. If you save a check-in, mention that it changes the local CSV in `data/`.

**Closing caption:** Orbit Health — Your health, in orbit. A local prototype inspired by public NASA Human Research Program and Canadian Space Agency resources. Synthetic demo data only; not a medical device or NASA/CSA product.
